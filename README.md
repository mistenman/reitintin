# HSL Journey Planner

A single-file, client-side journey planner for the Helsinki region, using the
[Digitransit](https://digitransit.fi) routing and geocoding APIs.

Open the page and paste a Digitransit subscription key when prompted. The key is
stored in your browser only and is not part of this repository.

- No map, no server, no build step at runtime.
- Walking speed presets and per-mode transit toggles.
- GPS origin, autocomplete, past-time warnings, and earlier/later departures.
- Works from any static HTTPS host, including GitHub Pages.
- Light and dark themes.

This repository contains the generated standalone build (`index.html`).
